# ParKing - SFML 2D Platformer Starter (Makefile)

Starter project in C++17 with SFML and Makefile.

## Prerequisites (Ubuntu / WSL)

```bash
sudo apt update
sudo apt install -y build-essential libsfml-dev
```

## Build

```bash
make
```

## Run

```bash
make run
```

## Clean

```bash
make clean
```

Controls:
- Move: `A/D` or arrow keys
- Jump: `Space` or `Up`
